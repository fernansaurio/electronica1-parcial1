# Electrónica 1 · Parcial 1 (ELC-115, UES)

Material de estudio ordenado para el Parcial 1 de Electrónica 1, Escuela de Ingeniería Eléctrica, Universidad de El Salvador.

## Cómo usarlo

1. Descarga el repositorio con **Code → Download ZIP** y descomprímelo.
2. Abre `index.html` en tu navegador. Es la página central con buscador: enlaza guías, material de clase, parciales anteriores y problemas resueltos.
3. Si tienes poco tiempo, empieza por `00_Guias_de_Estudio/04_Prediccion_y_Problemas_Resueltos.pdf`.

> GitHub no ejecuta `index.html` en línea. Hay que abrirlo desde la carpeta descargada para que funcionen los enlaces.

## Resolver problemas con ayuda de una IA

Usa [`00_Guias_de_Estudio/INSTRUCTIVO_RESOLUCION_PROBLEMAS.md`](00_Guias_de_Estudio/INSTRUCTIVO_RESOLUCION_PROBLEMAS.md). Contiene las convenciones del profesor, procedimientos por tipo de problema, un banco de respuestas verificadas y los errores conocidos en algunas fuentes.

**Convención clave del MOSFET:** `I_D = ½·K_N·(V_GS − V_t)²` con `K_N = k'n·W/L`.
